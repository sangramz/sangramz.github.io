# Sangram K Sundaray - Developer Resume

A modern, sleek, and professional resume designed specifically for software developers working in AI and Web Applications.

## Features

✨ **Modern Design**
- Clean, intuitive layout optimized for readability
- Gradient backgrounds and smooth animations
- Professional color scheme with blue/purple accents

🎨 **Responsive & Accessible**
- Fully responsive design that works on all devices
- Print-friendly styles for PDF generation
- Smooth scrolling and hover effects

🚀 **Developer-Focused**
- Specialized sections for technical skills
- Project showcase with technology tags
- Achievement-based experience presentation
- Areas of expertise highlighting

## Structure

### Sections Included:
1. **Header** - Personal information and contact details
2. **Technical Skills** - Categorized by Web Development, AI, and Digital Marketing
3. **Professional Experience** - Detailed achievements at Boldtribe Innovations
4. **Key Projects** - Showcase of major projects (Takafulik, Zymedics, Newztok)
5. **Areas of Expertise** - Core competencies and specializations

### Technologies Highlighted:
- **Web Development**: Python3, Django, REST APIs, PostgreSQL, JavaScript, React.js, HTML/CSS
- **AI & Machine Learning**: LLMs, Agentic AI, LangChain, Crew AI
- **Digital Marketing**: User Analytics, SEO, Natural Language Programming

## How to Use

1. Open `index.html` in any modern web browser
2. Customize contact information, skills, and experience as needed
3. For PDF generation, use browser's print function (Print styles are optimized)

## Customization

### Colors
The resume uses a professional blue-purple gradient theme. Main colors:
- Primary: `#667eea` to `#764ba2`
- Dark: `#1a202c` to `#2d3748`
- Light: `#f8fafc` to `#f1f5f9`

### Fonts
Uses Inter font family for modern, clean typography with multiple weights (300-700).

### Icons
Font Awesome 6.0 icons are used throughout for visual consistency.

## Print/PDF Export
The resume includes print-optimized styles. To generate a PDF:
1. Open in browser
2. Print (Ctrl/Cmd + P)
3. Select "Save as PDF"
4. Recommended: A4 size, no margins
