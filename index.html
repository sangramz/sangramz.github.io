Legal Document Abstraction Tool

Enterprise Contract Extraction & Clause Intelligence Engine

Built an AI-powered document abstraction system to automate the analysis of large volumes of legal PDF contracts for a Fortune 500 client engagement (PwC). The NLP pipeline parsed PDFs, extracted structured data (clauses, parties, dates, monetary amounts, obligations), and generated concise human-readable summaries using NLTK. A Django backend managed document storage, search indexing, and REST API delivery. Also trained and evaluated Named Entity Recognition (NER) models on legal text corpora using spaCy.

Measurable Impact

Reduced manual legal document review time significantly, enabling the client's legal team to process and analyze large contract volumes at scale.

Core Architecture

PyPDF2/pdfminer stream ingestion, custom-tuned spaCy/NLTK NER pipelines, and Django REST endpoints providing fast query retrieval.
